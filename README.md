# PGUPS Downloader

Локальный помощник для ЭИОС ПГУПС: скачивание отправленных работ и вложений, мониторинг оценок,
история изменений, календарь дедлайнов и каталог скачанных файлов.

> **Статус**: экспериментальный выпуск. Для проверки реальной авторизации/парсеров Moodle требуется собственная учётная запись ПГУПС. Приложение не является официальным сервисом университета.

## Установка (Fedora, Manjaro и другие Linux)

```bash
git clone -b fix/security-and-download-reliability https://github.com/Xver1Xrd/pgups-downloader.git
cd pgups-downloader
bash install-linux.sh
pgups --web
```

Интерфейс: http://127.0.0.1:5000. Скрипт создаёт изолированное виртуальное окружение
`.venv/` и локальную команду `~/.local/bin/pgups`. При необходимости добавьте её в `PATH`.

Ручная установка:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python pgups_downloader.py --web
```

Для CLI предпочтительнее вводить пароль через закрытый запрос:

```bash
pgups --login you@example.com --prompt-password --save-login
pgups --check
pgups --check --course 6964
pgups --workers 3
pgups --monitor --course 6964 --interval 60
```

Используйте только свою учётную запись и доступные вам учебные материалы. Слишком частые
проверки могут нагружать сервер, поэтому автоматическая синхронизация **выключена по умолчанию**,
минимальный интервал — 15 минут.

## Страницы веб-интерфейса

- `/` — оценки, прогресс и статусы заданий;
- `/download` — скачивание по выбранным курсам и типам файлов;
- `/calendar` — сроки сдачи (также экспорт `/api/calendar.ics`);
- `/history` — история изменений статусов;
- `/files` — индекс скачанных файлов и поиск по названиям;
- `/settings` — курсы, пароли, синхронизация и уведомления Linux.

История начинает заполняться **после первого успешного снимка** данных. Для фоновой
синхронизации веб-интерфейс должен оставаться запущенным. Системные уведомления используют
`notify-send` (`libnotify`) и отдельно включаются в настройках.

## Хранение данных и безопасность

Пароль для новых сохранений хранится в **системном хранилище секретов** через Python
`keyring` (например, GNOME Keyring / Secret Service). Существующая конфигурация с
паролем переносится в Keyring при обращении к web-приложению, если Keyring доступен.
При отсутствии хранилища настройка возвращает ошибку, а не пишет новый пароль в JSON.

- `config.json`, `cookies.txt` — в каталоге приложения, приватные права `0600`;
- `.secret_key` — ключ Flask, приватные права `0600`;
- `$XDG_DATA_HOME/pgups-downloader/pgups.sqlite3` (по умолчанию
  `~/.local/share/pgups-downloader/pgups.sqlite3`) — история, дедлайны, метаданные файлов;
- `~/Документы/pgups/` — локальные копии доступных файлов.

**Важно:** cookies также являются секретом сессии; храните их только на личном устройстве.
Сервер Flask слушает `127.0.0.1`, не публикуйте его напрямую в интернет. Если
задан `WEB_AUTH=user:password`, включается HTTP Basic Auth, но для удалённого
доступа дополнительно требуется HTTPS и отдельная проверка безопасности.

## Возможности загрузчика

- Выбор отдельных курсов, отправленных работ и вложений заданий;
- Поиск доступных дисциплин по ссылкам личного кабинета в настройках;
- Отмена активных загрузок и офлайн-просмотр последнего снимка оценок;
- поточная загрузка в случайный временный файл, проверка размера/хеша, атомарное сохранение;
- защита от выхода за пределы каталога и перенаправлений на другие домены;
- повторные попытки для временных сетевых ошибок;
- локальная дедупликация SHA-256.

Отмена загрузок работает кооперативно: текущие сетевые операции могут завершиться
не сразу, а незавершённые временные файлы очищаются.
При аварийном завершении процесса незавершённые загрузки не докачиваются автоматически.
Текущая модель задач работает в памяти; устойчивую очередь загрузок, интеллектуальную
инкрементальную синхронизацию и офлайн-индекс содержимого документов ещё предстоит добавить.

## Разработка и тесты

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install pytest
.venv/bin/python -m pytest -q
```

GitHub Actions выполняет синтаксическую проверку и офлайн-тесты. **Успешный CI не заменяет
интеграционные тесты с настоящим ЭИОС ПГУПС**. Не размещайте реальные логины, пароли,
cookies, личные оценки или скриншоты с персональными данными в issues и logs.

## Примечание о ветках

Репозиторий исторически имеет ветку `master` по умолчанию и более новую `main`.
Ветка `fix/security-and-download-reliability` содержит исправления и новые функции
и должна пройти интеграционное тестирование перед объединением с `main`.
